# Phase 5 — Computational Integrity Audit

Scope: every number in the published analysis path
(`analyze.py`, `create_jca_tables.py`, `write_jca_english.py`) was traced from
raw CSV -> cleaning -> statistic -> emitted output. Audit environment and
baseline are described in `BASELINE_INVENTORY.md`.

## Verdict

**No empirical-result hard-coding found.** All statistics in the published
path are recomputed from `data/terapeak_*.csv` (via `combined_cleaned.csv` /
`statistics_summary.csv`, which are themselves regenerated byte-identically by
`analyze.py`).

## Legitimate constants (not hard-coded results)

The following literals are prespecified study parameters, not empirical
outputs — reviewed and retained unchanged:

- Regulatory dates (2022-04-05, 2023-03-30, 2023-10-05, 2024-02-07, 2024-03-11,
  2026-01-01) — `analyze.py:32-95`, `create_jca_tables.py:74-77`.
- Phase labels/colors/linestyles for figures — `analyze.py:32-89`.
- Filter keyword lists (`exclude_keywords`, `vet_system_keywords`) —
  `analyze.py:142-153`.
- Plot styling (`rcParams`, color maps) and the asking-price collection date
  "27 March 2026" in the Table S1 caption — `create_jca_tables.py:309`.
- `asking_price_analysis.json` is generated data; `write_*.py` fall back to
  `asking_summary = None` when absent (they do not fabricate values).

## Risks noted (not violations)

- `statistics_summary.csv` and `combined_cleaned.csv` are checked-in generated
  artifacts; a stale checkout could mislead a reader who skips `analyze.py`.
  They are byte/content-identical after regeneration (float ulp differences only).
- `analyze_old.py` writes to the *same* output filenames (`combined_cleaned.csv`,
  `statistics_summary.csv`, `figures/fig*.png`) using a *different* cleaning
  pipeline (desflurane_ebay/sevoflurane_ebay/isoflurane_ebay + Worthpoint).
  Running it after `analyze.py` silently overwrites the published-path outputs.
  Flagged in README; left in place for provenance.
