## Methods-section verification

- "Spearman rank correlation between sale date and price" — matches code
  (`date_sold.toordinal()` vs `price_usd`).
- "Kendall τ, computed between the ordered regulatory phase (1–5) and sale
  price" — matches code (`period_num` 1–5). scipy default variant = tau-b.
- "Quarterly median prices were also assessed using Spearman correlation" —
  matches (`range(len(qm))` vs quarterly medians, `count>=3`).
- Cutpoint "1 January 2026" — matches `BAN_DATE`.
- Software versions stated in the manuscript (Python 3.12, pandas 2.2,
  scipy 1.14, statsmodels 0.14) differ from the audit environment
  (Python 3.10, pandas 2.3.3, scipy 1.15.3); all statistics nevertheless
  reproduced exactly, so version sensitivity is limited to float-ulp-level
  output differences and figure rendering.

## Notes / minor text observations (left unchanged)

  listing only post-* labels, while the code and the trend paragraph use a 1–5
  coding including `1_Pre-proposal`. Phase 1 is empty in the data (earliest
  sale 2023-03-28), so this wording does not affect any number. Documented
  here; the published text is not altered by this audit.
- Figure files `papers/fig1-fig6.tiff` are submission derivatives of the PNGs;
  the plotted values trace to `all_data` directly.
